# AGENTS.md — nplpackages/main

Public **readonly** NPL standard-library package. Strict subset of the private Paracraft script repo (`paraworld`). Do not treat this repo as writable upstream — sync comes from paraworld.

Install: `NPL.load("npl_packages/main/")` (usually loaded automatically at NPL startup).

## What is in this package

| Path | Role |
|------|------|
| `script/ide/` | IDE / framework (`commonlib`, `System.*`, UI, MCML, math, …) |
| `script/apps/WebServer/` | NPL web server |
| `script/kids/` | Partial Map3DSystem / legacy helpers (allowlisted only) |
| `script/sqlite/`, `script/test/` | SQLite bindings + tests |
| `Documentation/`, `npl_mod/` | Docs snippets + sample mod |
| `package.npl` | Package entry (`main = script/ide/System/System.lua`) |

**Not in this package:** Paracraft Creator (`script/apps/Aries/Creator/…`), Haqi client trees, `docs/` wiki, `Mod/`, art/assets, C++ ParaEngine.

For Paracraft app code see sibling package: [NPLPackages/paracraft](https://github.com/NPLPackages/paracraft).

## Hard rules (NPL)

1. Never Lua `require()` — use `NPL.load("(gl)script/...")`.
2. Modules: `commonlib.gettable("Namespace.Module")`.
3. OOP: `commonlib.inherit(parent, commonlib.gettable("..."))`.
4. User strings: `L"..."` / `L'...'`.
5. MCML: call `page:Refresh()` after data changes.
6. Match existing patterns and file headers; no foreign frameworks.

```lua
NPL.load("(gl)script/ide/System/System.lua");
local ToolBase = commonlib.gettable("System.Core.ToolBase");
```

Namespaces commonly used here: `System.*`, `commonlib.*`, `Map3DSystem.*`.

## Editing guidance

- This GitHub tree is a **published mirror**. Prefer changing the private paraworld script repo, then republish via the nplpackages sync skill.
- Smallest change surface; do not drive-by refactor.
- Framework / shared UI work → `script/ide/System/`.
- Web server work → `script/apps/WebServer/`.
